# GPro_Data

Data and figure archives for manuscript version V2.7.

## Downloads

The complete archives are available as GitHub Release assets.

- [GPro_Data.zip](https://github.com/haojiao/GPro_Data/releases/download/v2.7/GPro_Data.zip)
- [Figure.zip](https://github.com/haojiao/GPro_Data/releases/download/v2.7/Figure.zip)

GPro_Data.zip contains the original nested data and validation-material archives. Both uploaded ZIP files preserve the local originals.
